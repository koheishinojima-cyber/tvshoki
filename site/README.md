## 商品ページ（コンバージョンレイアウト）

`p/index.html` は WEB Designer 仕様のコンバージョンページ。ファーストビューはこの順だけ。

1. 番組名 + 放送日（このページで合っていることが分かる）
2. 画像があるときだけ出す。無いときはブロックごと省略（空き枠や「任意・未設定」は出さない）
3. 小さめのブランド + 商品名を H1（汎用の「紹介された商品」は使わない）
4. 一文「{番組名}で紹介」。ラベル「根拠URL」は出さない。公式の根拠 URL が必要なときは、その一文の href にする
5. 価格帯と送料は事実だけ
6. 全幅 CTA「商品を見る」（親指サイズ、モバイル）。`href="#"`。本番の追跡 URL は公開時に注入する
7. CTA 直下に「広告を含みます」

これ以外は置かない。長文 SEO、関連記事、テンプレート注意バナー、「紹介された商品」と商品名の二重表示はしない。

テンプレート本体はレイアウト確認用の仮テキスト（番組名 / 2099-01-01 / ブランド / 商品名）を含んでよい。HTML コメントでライブ案件ではないと明記する。ホームページからはリンクしない。パピコ / ガリガリ / 卵めん / 無印カレーをライブ案件として載せない。

CTA の `href` は公開時に本番の追跡 URL を注入する。このリポジトリでは `href="#"` のままにする。楽天 ID を invent しない。live の `hb.afl` URL を commit しない。
